Privacy Policy

T0LD Comentarios is a personal tool used exclusively by its developer on YouTube channels he owns. It uses the YouTube Data API to read the list and publication status of the owner's own videos and to post a comment on them as the channel owner.

No data from other users is collected, sold or shared. OAuth tokens are stored as encrypted secrets and are used only to perform the actions above. The tool does not access viewers' personal data.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
